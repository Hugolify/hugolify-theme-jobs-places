# hugolify-theme-jobs-places

## Install

Edit `config/_default/module.yaml` to install the `hugolify-theme-jobs-places` module:

### V2

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-jobs-places/v2
  - path: github.com/hugolify/hugolify-theme-jobs/v2 # required
  - path: github.com/hugolify/hugolify-theme-places/v2 # required
  - path: github.com/hugolify/hugolify-theme/v2 # required
```

### V1

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-jobs-places
  - path: github.com/hugolify/hugolify-theme-jobs # required
  - path: github.com/hugolify/hugolify-theme-places # required
  - path: github.com/hugolify/hugolify-theme # required
```
